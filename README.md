# 花光马斯克的钱 · Musk Money

一个纯前端的「虚拟花钱」解压模拟器：开局拥有约 **2.9 万亿元**虚拟资产（按 4000 亿美元折算），
在 **9390 件商品 / 12 个分类**里随便下单，看余额一路归零。

> 所有金额与交易都是**虚拟娱乐设定**，不涉及任何真实支付、真实商品或真实资产。

## 功能

- **资金面板**：剩余资产 / 已花掉 / 消费进度，数字用 tween 平滑滚动
- **实时搜索**：150ms 防抖，商品名、标签、二级分类都能命中，带清空按钮与结果计数
- **分类标签栏**：12 个分类 + 全部，横向滚动
- **批量购买**：卡片内 `−` / 数量框 / `+`，单次上限 9,999,999 件；余额不足会提示并拒绝
- **惊喜卡片**：每次下单弹出卡片 + Canvas 彩带粒子，最多同屏叠 3 张
- **购物清单**：按商品聚合件数与小计，卖出按买入原价退款，清空需二次确认；手机端为抽屉
- **本地存档**：余额、清单、成就写入 `localStorage`，刷新可恢复，支持「重开一局」
- **成就系统**：消费里程碑（1 亿 / 10 亿 / 100 亿 / 1000 亿 / 1 万亿）与趣味成就（1000 台 iPhone、火箭、海岛等）
- **虚拟滚动**：商品网格只渲染视口附近的行，9000+ 条数据也能流畅滚动

## 运行

不需要构建、不需要 npm、不需要后端。

```text
# 方式一：直接双击 index.html（file:// 协议可以正常运行）
# 方式二：起一个静态服务器（更接近线上环境）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 技术说明

- 原生 HTML + CSS + JavaScript（ES5 风格 IIFE，全局命名空间 `window.App`，不使用打包器）
- 商品数据是普通脚本 `src/data/products.js`，挂到 `window.MUSK_PRODUCTS`，因此 `file://` 可直接加载
- 动画优先用 GSAP（CDN）；加载失败时自动降级为 CSS keyframes，不会白屏
- 缩略图只用 emoji + CSS 渐变，不请求任何外部图片

## 目录结构

```text
index.html                 页面骨架与脚本加载顺序
styles/                    设计变量 / 布局 / 卡片 / 特效样式
src/store.js               全局命名空间、事件总线、localStorage 存档
src/economy.js             余额、购买 / 卖出 / 清空、金额格式化
src/achievements.js        成就定义与解锁检查
src/data/                  分类与商品数据（products.js 由脚本生成）
src/effects/               数字滚动、GSAP 适配层、彩带粒子
src/ui/                    资金面板、分类、搜索、商品网格、清单、惊喜卡片、Toast、弹窗
src/app.js                 启动、数据加载、模块串联
tools/gen-products.mjs     商品数据生成脚本（可重复运行，结果稳定）
tools/gen-report.md        数据集统计报告
```

完整的运行、改造、已知限制说明见 [使用教程.md](./使用教程.md)。
